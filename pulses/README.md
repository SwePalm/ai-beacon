# Weekly pulses

One file per weekly capture: `YYYY-MM-DD.md`.

Start from this shape:

```md
# Beacon pulse — YYYY-MM-DD

## Outcome

`material change` | `watch` | `no material change`

## Observations and candidate signals

| Item | Source and date | What it establishes | What remains unestablished | Terrain relevance | Next review |
|---|---|---|---|---|---|

## Due reviews and open claims

## Collection gaps

## Next attention
```

Pulses preserve an observation stream. They do not replace a dated run,
evidence grade, signal lifecycle record, or Choice Brief.
