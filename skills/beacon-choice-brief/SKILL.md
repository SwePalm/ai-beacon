# Beacon Choice Brief

Compose `beacon-brief.md` using the eight sections in `../../FOUNDING_HANDOVER.md`. Cite all observed, reported, and researched claims inline. Label interpretations and scenarios.

Write `beacon-brief.md` to the active run directory. Write for the middle 60% without flattening disagreement. End with questions and possible response terrain, not recommendations. Include an explicit counter-case, the source ledger, and dated open claims for calibration. Do not overwrite a prior run's brief or rewrite ledger records.
