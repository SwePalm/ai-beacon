# Beacon Historical Rhyme

Select one or two analogues that challenge the current interpretation. Produce `history.md` in the active run directory with similarities, differences, affected groups, evidence limits, and the lesson that must *not* be imported from history. Do not overwrite a prior run's history artifact.

Treat history as a comparison tool, never as a prediction engine.
