# Beacon Theme Selector

Read `../../references/THEME_MAP.md`. Select a condition, not a broad technology topic.

Produce `selection.md` in the active run directory with the condition, linked themes, why it may matter to ordinary people, an initial question, likely counter-interpretations, and explicit exclusion criteria. Preserve it as that run's phase artifact. Prefer evidence delta, public consequence, and relevance beyond early adopters over novelty or viral attention.
