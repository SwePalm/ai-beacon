# Beacon Theme Selector

Read `../../references/THEME_MAP.md`. Select a condition, not a broad technology topic.

Produce `selection.md` in the active run directory with the condition, linked themes, why it may matter to ordinary people, an initial question, likely counter-interpretations, and explicit exclusion criteria. Add a `Prior learning considered` section naming relevant calibration, unresolved signals, and open claims, and how they affected the choice. Preserve it as that run's phase artifact. Prefer evidence delta, public consequence, and relevance beyond early adopters over novelty or viral attention. If no condition clears that bar, record `No selection` and the evidence gap; no-change is valid.
