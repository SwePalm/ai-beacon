# Monthly learning reviews

One file per month: `YYYY-MM.md`.

Start from this shape:

```md
# Beacon learning review — YYYY-MM

## Material considered

## What changed, what did not, and what remains uncertain

## Signal lifecycle decisions

## Capability terrain

## Collection bias and gaps

## Next learning move

## Decision

`full run` | `narrow watch` | `adjust collection` | `no change` | `pause or archive`
```

The review is a record of what Beacon learned about the condition and about its
own instrument. It must preserve uncertainty and may conclude that the project
has not yet produced enough value to continue.
