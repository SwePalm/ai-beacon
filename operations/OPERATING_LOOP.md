# Beacon operating loop (initial)

## Purpose

This is a research rhythm for learning before publication. It should make useful
observations durable without mistaking a busy capture stream for understanding.

## Weekly pulse

Create `pulses/YYYY-MM-DD.md`. A pulse is not a Choice Brief or a full pipeline
run. It records only enough to support later comparison:

1. Scan the current AI condition through the minimum US / EU / China lens where
   sources permit, while remaining alert to relevant developments elsewhere.
2. Retain a small number of source-linked observations or candidate signals.
3. State what each item establishes, what it does not establish, and why it may
   matter for the capability terrain.
4. Check signals whose review date is due, open claims, and calibration notes.
5. End with one of: `material change`, `watch`, or `no material change`.

Do not add a pulse item to a formal ledger merely because it is recent or
interesting. Promotion still requires the appropriate evidence grade and
append-only record. A quiet pulse is a valid result.

## Monthly learning review

Create `learnings/YYYY-MM.md`. Read that month's pulses alongside relevant runs
and state records. The review asks:

1. Which signals strengthened, weakened, contradicted, expired, or remain open?
2. Which conditional capacities shifted in the terrain, and at what locus
   (person, team, institution, public system)?
3. What was absent or over-represented in collection, including geography,
   language, occupation, and source type?
4. Does the evidence justify a full pipeline run next month, a narrower watch,
   a method proposal, or no change?
5. What should the next month's collection pay attention to?

The review may append lifecycle records or propose a method change, but it may
not rewrite past records. Changes to skills, references, evidence definitions,
or the theme map remain human-approved.

The initial reminder combines the two rhythms: it runs a weekly pulse every
Friday at 09:00 Europe/Stockholm time and, on the first Friday of a month,
reviews the preceding calendar month's pulses. This keeps one attached reminder
while the experiment is early.

## Review gates

- No external publishing is implied by either cadence.
- Source discovery is not validation; retain direct links and dates so later
  grading can test the claim.
- Direct research remains the default collector. Optional discovery tools must
  be evaluated as adapters, not treated as evidence authorities.
- A full run remains intentional: select -> sweep -> grade -> compare -> weave
  -> brief -> calibrate.
